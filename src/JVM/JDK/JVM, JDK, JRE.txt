1. JVM (Java Virtual Machine)- виртуальная машина Java. Принимает байт-код конкретной программы
и исполняет его (интерпретация+компиляция). Является ядром всей Java-платформы, работает в фоне.

Состоит из нескольких частей:

-Загрузчик классов — находит и подгружает файлы с байт-кодом (.class).
-Исполнительный движок — читает байт-код и превращает его в команды, понятные конкретному компьютеру.
-Сборщик мусора — автоматически удаляет из памяти объекты, которые больше не нужны.
-Области памяти — куча, стек и другие, где хранятся данные во время работы.

2. JRE (Java Runtime Environment)- среда выполнения Java. Представляет собой директорию с файлами:
JVM, библиотеки, инструменты. Работает в фоне, запускает готовые приложения, не содержит средств для разработки.

3. JDK (Java Development Kit) — комплект разработки Java. Представляет собой директорию с файлами:
JRE, компилятор (javac, превращает исходный код в байт-код), отладчик. Является инструментом для компиляции
и запуска программы. Работает при запуске.


Разработчику требуется JDK, чтобы писать и собирать программы.
Пользователю достаточно только JRE (чтобы запускать готовые программы). Насколько я знаю,
программы идут со своей JRE внутри, так что пользователю вообще ничего ставить не надо.

Байт-код представляет собой универсальный язык для JVM. На любом компьютере,
где есть JVM код выполняется одинаково. Поэтому не нужно переписывать программу под каждую систему.
Выглядит как сжатый набор инструкций для JVM, хранится в файлах с расширением .class,
которые создаются компилятором из исходного кода.
